# Agent 工具调用输出纪律

状态：implemented
类型：process
Owner：backend/package/yuxi/agents/buildin/chatbot/prompt.py

## 问题

模型在发出结构化工具调用时偶尔同时输出“让我查找”“已经定位”等过程正文。前端会把这些片段当作回答过程展示，增加拖沓感，也可能把尚未核实的中间判断误认为结论。

## 决策

- 系统提示明确要求：工具调用消息正文为空，只发送结构化调用；工具返回后只输出一次最终答案。
- 禁止“我找到了”“让我确认”“接下来”等自我对话，并禁止把多轮工具结果依次复述成重复结论。
- 该约束属于模型行为引导，不升级为安全边界或协议校验；Run、消息和错误终态仍由现有结构化事件拥有。

## 替代方案

- 在流式服务中丢弃所有工具调用前正文：可以硬性隐藏过程，但可能误删模型同一消息中的有效用户内容，并扩大协议处理面。
- 在前端按中文短语过滤：依赖语言和可变文案，容易漏判与误判。
- 完全隐藏工具过程面板：视觉更干净，但会损失必要的执行可观察性。

## 后果

多数工具轮只保留结构化调用和最终答案，提示词不能保证所有供应商模型完全服从。真实表格验收仍观察到一次简短定位句，因此产品不能把“绝不出现过程话术”写成硬保证；若后续要强制，需要另行设计结构化输出协议并请示代码改动。
